# Gusto design references

The project's design brief is the [Design section of the project guide](../AGENTS.override.md#design):
a warm cookbook with cream paper, paprika red and herb green, Fraunces display
type and Hanken Grotesk text. The implemented styles and responsive behavior
live in [gusto/static/style.css](../gusto/static/style.css).

Use that brief and the existing components for UI work. This file defines no
separate design tokens or additional visual policy. Update the project guide
and implementation together when an authorized task changes the design.
